About the Detectra Project:
  • Detectra is a browser-based phishing detection tool that provides real-time analysis of potentially malicious links. Using a machine learning model trained on a diverse dataset of legitimate and phishing URLs, it evaluates structural and lexical patterns to assess the likelihood of a link being unsafe.

  • The system delivers instant results through an accessible interface with both light and dark modes, allowing users to make informed security decisions without interrupting their browsing experience.

  • By focusing on feature-based URL analysis instead of static threat lists, Detectra improves detection accuracy for emerging and previously unseen phishing tools.
